public Builder (String peerBluetoothAddress)

Constructs a new Builder for creating a bluetooth rssi ranging session.

Valid Bluetooth hardware addresses must be upper case, in big endian byte order, and in a format such as "00:11:22:33:AA:BB". The helper BluetoothAdapter.checkBluetoothAddress(String) is available to validate a Bluetooth address.

Parameters
peerBluetoothAddressString: The address of the peer device must be non-null Bluetooth address.
