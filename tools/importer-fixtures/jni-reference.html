NewObject, NewObjectA, NewObjectV

jobject NewObject(JNIEnv *env, jclass clazz, jmethodID methodID, ...);

Constructs a new Java object. The method ID is obtained by calling GetMethodID().

NewObjectA

Programmers place constructor arguments in an args array of jvalues.

PARAMETERS:

env: the JNI interface pointer.

clazz: a Java class object.

GetMethodID

jmethodID GetMethodID(JNIEnv *env, jclass clazz, const char *name, const char *sig);

Returns the method ID for an instance method of a class.

RETURNS:

Returns a method ID.

Call<type>Method Routines

NativeType Call<type>Method(JNIEnv *env, jobject obj, jmethodID methodID, ...);

Invokes an instance method according to the specified method ID.

PARAMETERS:

obj: a Java object.

GetArrayLength

jsize GetArrayLength(JNIEnv *env, jarray array);

Returns the number of elements in the array.

PARAMETERS:

env: the JNI interface pointer, must not be NULL.

array: a Java array object, must not be NULL.

RETURNS:

Returns the length of the array.
