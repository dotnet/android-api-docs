RangeTemplate

public RangeTemplate (String templateId, float minValue, float maxValue, float currentValue, float stepValue, CharSequence formatString)

Construct a new RangeTemplate. The range must be valid, meaning:

  • minValue < maxValue
  • minValue < currentValue
  • currentValue < maxValue
  • 0 < stepValue

The current value of the Control will be formatted accordingly.

Parameters
templateIdString: the identifier for this template object.
This value cannot be null.
minValuefloat: minimum value for the input
maxValuefloat: maximum value for the input
currentValuefloat: the current value of the Control containing this object.
stepValuefloat: minimum value of increments/decrements when interacting with this control.
formatStringCharSequence: a formatting string as per String.format used to display the currentValue. If null is passed, the "%.1f" is used.
Throws
IllegalArgumentExceptionif the parameters passed do not make a valid range.
